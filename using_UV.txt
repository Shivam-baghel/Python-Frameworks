go to particular directory. inside the directory execute the below commands :

to create a project using uv :
	uv init <project_name>

if a project already exists and u didn't create it with uv then :
	uv init
	
(uv will automatically create a virtual env for the project)

create a virtual environment for python.

	(use command which works for you)
	cmd: python3 -m venv .venv  
	or
	cmd: python -m venv .venv

(.venv is name, u can give any name, remember to use that particular name while activating the virtual environment)
Activate the virtual environment for the project
	On Windows:
	.venv\Scripts\activate
	
	On macOS/Linux:
	source .venv/bin/activate


Install Dependencies: If your project has a requirements.txt file, you can install the required packages using:

	pip install -r requirements.txt

*Generate the requirements.txt File: Run the following command:
	pip freeze > requirements.txt

*Verify the Installation: You can check that the packages are installed correctly by running:
	pip list
	
*Deactivate the Virtual Environment: When you’re done working in the virtual environment, you can deactivate it by simply running:
	deactivate

install fastapi using pip : pip install fastapi[standard]
