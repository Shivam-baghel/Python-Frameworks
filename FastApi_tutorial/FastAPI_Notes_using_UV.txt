go to particular project directory. inside the directory execute the below commands :

to create a project using uv :
	uv init <project_name>

if a project already exists and u didn't create it with uv then :
	uv init
	
(uv will automatically create a virtual env for the project if run the project using uv)

create a virtual environment for python.

	(use command which works for you)
	cmd: uv venv <environment name> 
	example: uv venv .venv
	(.venv is name, u can give any name, remember to use that particular name while activating the virtual environment)

Activate the virtual environment for the project
	On Windows:
	.venv\Scripts\activate
	
	On macOS/Linux:
	source .venv/bin/activate
	source .fastapiVenv/bin/activate


	
*Deactivate the Virtual Environment: When you’re done working in the virtual environment, you can deactivate it by simply running:
	deactivate

install fastapi using uv : uv add fastapi[standard]

To run the fast api application on the server. There are multiple commands
	command1 : uvicorn filename:app --reload in terminal
		Ex: uvicorn books:app --reload
		(reload makes sure that if any changes is made in project then fastapi automatically restarts)
		(this filename would be the file where fastapi is created and "app" could be any name given by you to call fastapi)
	
	command 2 : fastapi dev filename.py (this will run the server in devlopment mode)
		Ex: fastapi dev books.py

	command 3 : create main function where fastapi is made to run:
			ex:
				app = Fastapi()
				
				if __name__ == "__main__":
					import uvicorn
					uvicorn.run(<app_name>, host= '0.0.0.0',port= 8000, debug=True)
					
					ex: 
					uvicorn.run(app, host= '0.0.0.0',port= 8000, debug=True)
				
				use the below main function for reloading the fastapi project automatically.
				
				if __name__ == "__main__":
					# to reload use app as an import string to enable reload
					uvicorn.run("books:app", host="0.0.0.0", port=8000, reload=True)
					

for encrypting passwords or storing hashed password we need to hash or encrypt the password, lets learn how to do that.

	install passlib and correcct version of bcrypt that will go with passlib

	Ex: pip install passlib (for installing passlib)
		pip install bcrypt==4.0.1 (for installing bcrypt)

	import CryptContext from passlib.context
	create variable bycrypt_context= CryptContext(schemes=['bcrypt'], deprecated='auto')

	to encrypt use bycrypt_context.hash("The value you want to hash")
